B — today внутри range (будущие даты неактивны)
Правки (панель A): паддинг панели 16px со всех сторон; даты между from/to — сплошная синяя лента с белым текстом (концы скруглены по внешним сторонам, одиночный день — полный круг); все круги — фиксированного диаметра, центрированы в ячейке (ячейка не квадратная).
today — маркер одинаков внутри и вне range: круг 40px. Вне range (A, 10-е) — бледно-голубой, чёрный текст; внутри range (B, 10-е) — день остаётся белым в синей ленте, круг полупрозрачно-белый поверх ленты (стили range не тронуты, синего остаётся ~2px вокруг круга).
Идеи (панель B): hover-круг на обычных датах (правило :hover, в макете не показано); будущие даты неактивны — защищает от выбора периода без данных. Реализация — classNames в DateRangePicker.tsx + disabled={{ after: today }}, паддинг — обёртка панели.
